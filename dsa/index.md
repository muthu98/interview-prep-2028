# 🎯 Interview Strategy

When solving any problem, follow this order:

1. Understand the problem.
2. Identify the pattern.
3. Explain the algorithm in plain English.
4. Write the brute-force solution.
5. Optimize the solution.
6. Analyze Time & Space Complexity.
7. Think about interview follow-up questions.
8. Write revision notes.
