# Binary Search

## Definition

Binary Search repeatedly divides the search space into two halves until the target is found or the search space becomes empty.

---

## When to Use

- Sorted array
- Sorted answer space
- Search problems
- Peak finding
- Rotated sorted array

---

## Algorithm

1. Initialize left and right pointers.
2. Find the middle element.
3. Compare target with middle.
4. Discard one half.
5. Repeat until found or pointers cross.

---

## Complexity

Time

```
O(log n)
```

Space

```
O(1)
```
